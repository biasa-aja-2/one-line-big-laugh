One funny line: my bank flagged my own spending as fraud — and honestly, it had a point. Pure Python stdlib; it writes the line to `entry.txt`.

> My bank flagged my own spending as fraud, and honestly, it had a point.

## Why this line

- **A real joke with a turn:** the setup promises a complaint about the bank, then the speaker sides with the bank against himself — the accuser becomes his own defence witness.
- **Tight:** 71 characters, every word earning its place; setup, turn and sting in a single breath.
- **Fresh:** not a pun telegraphed from the first word, and not a recycled joke — the punchline is agreeing with the fraud department.
- **Clear on first read:** no explanation needed, no second line to make sense.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`): 71 characters, one line, no trailing newline.
